# Power BI PBIX Creation Steps

Power BI `.pbix` files must be saved from Power BI Desktop. This repository includes the dashboard data and visual design needed to create the PBIX quickly.

## Files to Use

```text
dashboard/customer_shopping_dashboard_data.csv
dashboard/customer_shopping_dashboard.png
dashboard/visualization_guide_powerbi_tableau.md
```

## Steps

1. Open Power BI Desktop.
2. Select `Get data` -> `Text/CSV`.
3. Load:

```text
dashboard/customer_shopping_dashboard_data.csv
```

4. Build the visuals from:

```text
dashboard/visualization_guide_powerbi_tableau.md
```

5. Save the file as:

```text
Customer_Shopping_Behavior_Dashboard.pbix
```

6. Upload the `.pbix` file to the `dashboard/` folder in GitHub.

## Recommended Dashboard Pages

- Executive Overview
- Customer Segmentation and CLV
- Product and Seasonal Performance
- Discount, Churn, and Retention
