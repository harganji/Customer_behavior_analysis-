## Featured Project

### Customer Shopping Behavior Analysis

End-to-end retail analytics project using Python, MySQL, SQL, Power BI planning, customer segmentation, and machine learning.

What I built:

- Cleaned and transformed 3,900 customer shopping records
- Loaded cleaned data into MySQL
- Wrote advanced SQL queries using CTEs and window functions
- Built RFM segmentation and estimated CLV analysis
- Created churn-risk and subscription conversion logic
- Added RandomForest models for customer value prediction
- Designed a four-page Power BI dashboard structure
- Converted analysis into business recommendations

Key business result:
The project identifies high-value customer groups, discount inefficiencies, category revenue drivers, and retention opportunities that can help a retail team improve campaign targeting.
