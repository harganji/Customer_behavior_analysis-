# Final Project Summary

## Project

Customer Shopping Behavior Analysis

## Business Goal

Help a retail business understand customer value, revenue drivers, discount performance, and retention opportunities using customer shopping behavior data.

## What Was Built

- Cleaned Python dataset pipeline
- MySQL-ready customer table
- Advanced SQL analysis workbook
- RFM segmentation
- Estimated CLV proxy
- Churn-risk flag
- Discount impact analysis
- RandomForest machine learning models
- Power BI dashboard blueprint
- Recruiter-ready GitHub README

## Main Insights

- Total revenue: $233,081
- Male customer revenue: $157,890
- Female customer revenue: $75,191
- Highest revenue category: Clothing at $104,264
- Highest revenue season: Fall at $60,018
- Subscribers show stronger estimated CLV than non-subscribers
- Discounts do not substantially increase average order value
- High-value non-subscribers are a strong subscription conversion opportunity

## Business Impact

The analysis enables the business to:

- Reduce inefficient discounting
- Prioritize high-value customers
- Build targeted subscription campaigns
- Improve seasonal merchandising
- Create segment-specific retention strategies
- Align Power BI reporting with executive KPIs

## Why This Stands Out

This project goes beyond basic EDA. It uses the same flow expected in a professional analytics role:

problem -> data cleaning -> SQL validation -> segmentation -> predictive modeling -> dashboard design -> business recommendations.

It is designed to be discussed in interviews as a complete business analytics case study.
